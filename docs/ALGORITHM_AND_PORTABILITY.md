# 算法、移植改动与已知限制

## 流程

1. 检测表盘、针搜索区、轴心搜索区。
2. 已标定单图先核对SHA、尺寸和目标框绑定；轴心从图像圆证据求出，不直接取框中心。
3. 在针搜索区提取近轴长边，要求可见针身支撑并排除竞争长方向；彩色针有独立图像检查。返回的是方向射线端点，不保证是真实针尖。
4. 根据图像轴心计算每个刻度角度，使用atan2处理象限和跨零，将当前针向放到相邻刻度间插值。单位和标值来自人工标定。
5. 多表/多针、错误标定绑定、针向不充分或配准不足时输出 `needs_review`，数值为空。

763模板实验额外进行静态面SIFT匹配、拟合/留出核验、局部灰度与梯度相关、往返与唯一性检查，再产生仅绑定本次校正图的运行标定。只允许指定的源模板profile被打开；不读取目标人工标定来制造模板复用成功。

## 为交接做的改动

- 原 `best.pt`、电脑 `best.onnx` 和核心几何源码按SHA原样保留。
- 新增轻量ONNX CPU解码与运行入口，不要求安装PyTorch；浮点X5六头只用于CPU协议核对，不冒充BPU运行。
- 标定的图片路径改为仓库相对路径；原点击值和坐标、原图SHA不变。配置中记录原profile SHA，区分字节适配和标定内容。
- 763实验 `--check` 改为按仓库根目录解析相对源图，选图默认目录改为samples。其他算法门槛未变。
- 原47项reader测试仅调整fixture路径，并把依赖图片放入tests/fixtures；断言和核心几何未删改。新增检测协议和错图绑定测试。
- 初版轻量解码复用了单一缩放比例，128、5两图与历史ONNX读数存在差异。失败报告保留于 `evidence/validation-before-axis-scale-fix.json`。整数resize的横纵实际比例不同；修复为逐轴还原后，11条历史ONNX数值全部复现。没有改模型、标签、刻度或读数规则。

## 最新小量程失败案例

`0 → 10`为另一组0～0.6 MPa同表型候选。两张320×240，均有训练重合。新实验中10两个针ROI方向只差约1.5412°，但41对静态匹配的27个拟合内点凸包覆盖22.76%，不足原25%门槛；若干外圈标定点也缺空间支撑。10无已接受数值。

该案例见 `evidence/small-template-target-10.json` 和诊断图。已知H控制只是同一原图的受控变换，不是现场精度。本仓库没有把尚未通过的小量程候选设为部署默认入口。
